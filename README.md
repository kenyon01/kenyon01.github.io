# Qingyan — Personal site

阿岩的个人主页与博客，托管于 GitHub Pages。

## 具身智能学习专题

主导航最初设有三个学习专题：`/robotics/`（具身智能）、`/post-training/`（模型后训练）、`/quant/`（量化交易）。编辑文章时在「所属栏目」选择对应栏目，公开并上架后自动收录。没有文章时显示整理中的说明，不生成示例文章。

专题入口：`/robotics/`，首页和导航均有链接。文章沿用下方的私有原稿发布流程：在后台将「所属栏目」设为「具身智能」，设为公开并上架后，自动收录到专题。可同时添加 `感知与接口`、`策略与控制`、`仿真与接触`、`实验方法` 标签，用于主题筛选。栏目选择优先于标签，修改栏目即可移动文章。未填写栏目字段的旧文章暂按同名标签兼容归类。

## 手动创建栏目

文章编辑页在「所属栏目」旁点击「添加栏目」，填写名称（如「数字信号处理」）、简介、导航顺序以及是否显示在主导航，添加后随文章一起保存。也可以从后台左侧「栏目管理」独立新建、修改栏目。栏目名称和简介是公开内容，保存会触发公开站点更新；即使文章仍是私有，新增栏目设置也会公开。文章编辑页的「所属栏目」读取所有已保存栏目，可搜索名称。

原稿保存在私有仓库 `_topics`，文章引用栏目文件名对应的稳定标识，改栏目名称不会改变已有文章归属。同步程序只导出规定的公开设置，生成本仓库 `_topics`，Jekyll 自动生成页面、主导航和文章返回链接。新栏目的地址为 `/topics/<自动生成的标识>/`，原有三个栏目保持原地址。其他文章也有独立页面，但默认不显示在导航。

栏目不提供删除入口，避免已有文章失去归属；可以改名、修改简介、排序或关闭导航。新栏目通常只需填写中文名称，网址标识自动生成。`_topics` 与 `_posts`、`article-media` 都是同步生成的文件，不要在公开仓库直接修改。GitHub Pages 自动发布；腾讯云镜像仍按现有部署流程同步。

## 章节与阅读布局

栏目页面和文章使用三栏布局：顶部导航切换栏目，左侧仅展示当前栏目内的「章 → 节 → 文章」树形目录，中间是正文，右侧是当前页面 H2–H6 标题导航。左侧目录可展开、折叠、搜索并标出当前文章，搜索范围限定当前栏目；进入文章后顶部继续标明所属栏目。窄屏把目录改为可展开面板，正文始终可读。

先在后台「栏目管理」创建栏目，再在「章节管理」创建章节，选择所属栏目、可选的上级章节和顺序。章节最多嵌套 8 层，空章节也会出现在该栏目的学习目录中。同层章节的顺序数字越小越靠前。

「章节管理」列表上方可按栏目勾选筛选，支持同时查看多个栏目；点击「全部栏目」或取消全部勾选即可恢复。筛选选项会自动包含新建的栏目。

点击「调整章节顺序」可在每个栏目、同一上级下拖动章节，或使用上移/下移按钮；点击「完成」后保存，取消则放弃本次调整。排序期间保留栏目筛选并暂时锁定筛选项，不改变章节的上下级关系。

章节列表按树形显示，通过缩进和级别标签区分层级，点击章节左侧箭头可折叠/展开。移动父章节会携带整个分支；所有层级都只能在同一父章节下排序，不能跨栏目或跨父章节拖动。折叠的子章节仍会保留在排序保存中。

写文章时只需选择「所属栏目」和「所属章节」；章节选项显示完整层级，例如「第一章 基础 / 1.1 接口」。不选章节则直接放在栏目下，切换栏目会清空原章节。「文章顺序」控制同一位置的文章排列。章节使用固定标识关联文章，重命名或调整同栏目内的层级会自动更新文章目录，不改变文章网址。章节名称和结构会公开显示，请勿在其中填写私密信息。

专题支持标题、摘要与标签关键词搜索；不依赖 JavaScript 也能查看完整文章列表。首批内容于 2026-10-27 整理自 2026-09-18 的实验记录，明确标注了历史背景与验证边界。

腾讯云镜像部署说明见 `deploy/README.md`。镜像只部署 GitHub Pages 生成的公开站点，不能上传整个工作目录（其中含本地私有原稿与凭据目录）。

## 写一篇新文章

在私有原稿仓库 `kenyon01/blog-private` 的 `_posts` 目录新建 Markdown 文件，文件名格式：

```text
YYYY-MM-DD-english-slug.md
```

文章开头使用以下 Front Matter：

```yaml
---
layout: post
title: "文章标题"
description: "一句话摘要"
tags: [标签一, 标签二]
topic: general
reading_time: 5
published: false
visibility: private
---
```

私有仓库推送到 `main` 后会同步公开内容；只有 `published: true` 且 `visibility: public` 的文章才会进入公开博客。本仓库的 `_posts`、`article-media` 是生成的公开副本，不要直接编辑。

## 在线写作后台

访问 [`/admin/`](https://kenyon01.github.io/admin/)，使用 GitHub 登录，即可在线新建、编辑和发布文章。

1. 新建文章默认“未上架 · 私有”，点击保存后保存在私有仓库。
2. 在文章列表点击“编辑”继续完善，保存不会改变上架状态。
3. 私有文章上架后，在后台列表点“阅读”。其他人无法通过公开网站或公开仓库访问。
4. 想对外公开时，点击“设为公开”并上架；同步及 GitHub Pages 构建成功后上线。
5. 点击“下架”或“设为私有”会在同步完成后撤下公开副本，原稿保留。
6. 已上架且公开的文章编辑保存会更新网站。状态反映保存设置，可点击“查看同步结果”检查是否成功；网站更新还需等待 Pages 构建。

原稿和新上传图片保存在私有仓库，GitHub 验证登录权限；当前仅站主有仓库权限。后台阅读使用经认证获取的内容和图片，外部图片不会自动加载。公开转私有无法清除既有 Git 历史、搜索缓存或他人副本。

- 如使用细粒度 Token 登录，需要本仓库 Contents 和 Pull requests 读写权限；Token 不应写入任何仓库文件。
- 图片上传到私有仓库的 `article-media`；仅公开文章引用的图片同步到公开仓库。
- 列表按钮管理上下架，编辑器中不显示可见性开关。

## 实验视频（腾讯云存储）

在文章编辑页展开「实验视频」，添加一项，填写说明，使用「上传视频到腾讯云」选择 MP4（H.264 8 位视频、AAC 音频），单个不超过 200 MiB。上传完成自动填入 HTTPS 链接，再保存文章。也可以「选择已上传视频」复用文件。视频显示在文章正文下方。

视频字节只保存在腾讯云 `/opt/robot-learning/media/videos/`，不会写入私有或公开 GitHub 仓库。现有 GitHub 登录用于验证站主的上传权限。普通媒体入口拒绝视频，普通附件最大 10 MiB。上传按钮会显示进度，失败保留原链接，可重试。

**视频链接是公开的，私有文章不会使已上传的视频变为私有。** 仅上传适合公开展示的素材。移除文章中的视频项只是移除引用，不删除服务器文件；如需删除视频请由管理员确认引用后处理。站点重新部署不会覆盖视频目录。

两个站点使用 `https://www.nlearn.net/robot-media/videos/` 播放同一份视频；该域名在同一腾讯云服务器已有 HTTPS。文章仍遵循原有公开/私有发布规则，腾讯云网页镜像仍需同步构建产物。

服务部署、配额、检查与回滚见 `deploy/media/README.md`。

## 后台构建

后台基于 Sveltia CMS 0.218.0，固定源码提交 `00c44da6b919d15e559f51ca54cd96237ae556ee`。定制补丁位于 `cms-customization/publication.patch`，只增加文章列表操作与状态，复用原生保存、冲突检测与登录。

使用 Node.js 24.19+ 和 pnpm，运行 `powershell -File cms-customization/build.ps1` 可重建 `admin/vendor/sveltia-cms.js`。构建目录 `.cms-build` 不提交。保留上游 MIT 许可证；语言包等按上游固定版本从 CDN 加载。
完整 HTML 实验报告可以通过文章的「HTML 实验报告链接」嵌入，保留原排版、图表、视频和数据下载。报告文件托管在腾讯云，GitHub 只保存摘要和链接；准备方式见 [HTML 报告发布](deploy/reports/README.md)。
