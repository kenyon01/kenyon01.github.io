旋钮的电流采样板有两路输出，SimpleFOC 的图上恰好有两条电流曲线。一根线是不是专门测 D，另一根专门测 Q？可以想一个判别方法：拔掉编码器，电流采样板仍能给出两个电压，可是控制器已经不知道转子的 D 轴朝哪儿了。**硬件测量的是固定在定子上的 A、B 两相电流。要得到随转子旋转的 D、Q 分量，还得知道转子的电角度。** 上一课的图画出了这两根旋转的坐标轴。[第 1 课：为什么 FOC 要有 D 轴和 Q 轴？](/blog/2026/11/06/foc-dq-axes/)

## 第一步：ADC 怎样把电压读成电流？

在我们的 DengFOC V4 上，电机接 M0。A 相和 B 相各有一个采样通道，分别接到 ESP32 的 GPIO39 和 GPIO36。电流流过分流电阻时产生微小压降，INA240 把压降放大，ESP32 的模数转换器（ADC）再读出电压。

为什么停机时读到大约 **1.69 V**，电流却接近零？因为相电流有两个方向，采样输出给零电流留了一个中点。估算电流时，要先减去该通道在零电流时的电压。我们的保护程序按 **0.01 Ω** 分流电阻和 **50 倍**增益换算，合起来就是 **500 mV/A**。例如，相对零点下降 10 mV，对应电流读数 −0.020 A。负号表示相对于约定正方向反向流动。每个通道使用自己的零点。

## 第二步：两路测量为什么够用？

对这只三线电机，把流入电机约定为正。在同一时刻，从一根线流进去的电流，还得从另外的线流出来，因此 **ia + ib + ic = 0**。来读一条旋钮停机时的真实记录：

```text
ia_A=-0.0068   ib_A=0.0060   ic_A=0.0008
```

A 相读到 −6.8 mA，B 相读到 +6.0 mA。用两者推算，C 相是 **−(−6.8 + 6.0) = +0.8 mA**，与日志一致。这里的 C 相数字完全由前两个数决定。如果 B 通道有偏差，C 的推算值也跟着变；把三项加起来等于零，只能检查这笔算术。这组停机读数还包含采样噪声，不能据此推断旋钮正在输出可感知的力矩。

## 第三步：同一组相电流怎样变成 Id 和 Iq？

先把三相绕组想成三把彼此相隔 120° 电角度的尺。**Clarke 变换**把这些方向上的电流合成为一个平面矢量，再用固定的两根直角轴 α、β 描述它。按本项目 SimpleFOC 的约定，α 轴与 A 相对齐：

```text
iα = ia
iβ = (ia + 2 × ib) / √3
```

接着用**转子的电角度 θ**旋转尺子，读出这个矢量沿 D 轴和 Q 轴的投影。这一步叫 **Park 变换**：

```text
Id =  iα × cos θ + iβ × sin θ
Iq = −iα × sin θ + iβ × cos θ
```

用一个能心算的例子看它的作用。假设 **ia = +20 mA、ib = −10 mA**，那 ic 就是 −10 mA。代入第一组公式，得到 **iα = 20 mA、iβ = 0**。电流箭头正好沿着固定的 α 轴。现在只改变观察这根箭头的转子位置：

| 假设的转子电角度 | D 轴上的读数 | Q 轴上的读数 | 怎么理解 |
|---|---:|---:|---|
| θ = 0° | +20 mA | 0 mA | D 与 α 同向，箭头全部落在 D 上 |
| θ = 90° | 0 mA | −20 mA | D 已转过四分之一圈，箭头指向负 Q |

这两个位置是假设的两个瞬间，用来单独考察换坐标的效果。**只给相电流，无法唯一确定转矩电流 Iq**。在真机上，AS5600 提供机械角度，固件结合极对数、方向和校准零点得到 θ。GUI 的 `Cd`、`Cq` 就来自这一计算。本项目图表用 mA，诊断行中带 `_A` 的字段用 A。[SimpleFOC 2.2.1 的电流变换源码](https://github.com/simplefoc/Arduino-FOC/blob/v2.2.1/src/common/base_classes/CurrentSense.cpp)

读自己的日志时还有一个细节：这版固件响应 `J` 时，先读一次相电流，再由库重新采样并计算 D/Q。因此同一行中的 `ia_A`、`ib_A` 和 `id_A`、`iq_A` 来自相邻的两次采样。未校准时诊断程序还会暂用 θ = 0。想练公式，用上面的同一组假设值；想检查真机零点，则看电机失能时两路相电流的波动。

## 随堂练习：这条过流日志提供了几份证据？

下面是一次校准中真正触发停机的记录。只看已有日志就能做题，无需让电机通电。

```text
OC_TRIP source=watchdog_adc session=calibration elapsed_us=1406776
        ia_A=0.0223 ib_A=-0.4982 ic_calc_A=0.4759 threshold_A=0.30
```

先自己判断三个问题：**哪个实测通道越过了阈值？用笔算出的 C 相是多少？如果调低 Q 轴的 P，这条记录能否说明问题就会消失？**

**对照答案。** B 通道读到 −0.4982 A，绝对值超过 0.30 A。由 A 和 B 得到 C = −(0.0223 − 0.4982) = +0.4759 A。这里有一个直接越限的通道，C 复用了同一笔 B 数据。保护任务在校准期间检查的是相电流，当时还没进入 Q 轴电流闭环。能确定的是软件读到了越限值并关断；要区分绕组真实电流尖峰与采样瞬态，还需要独立测量。下次看波形时，可以先问一句：**这个数是从哪根线上量来的，还是用哪些量算出来的？**
